# Incident Roles

Incident commander:
  Owns pace, decisions, severity, and handoff.

Operations lead:
  Runs approved diagnostics and mitigation.

Communications lead:
  Writes internal and customer-facing updates.

Planning lead:
  Tracks timeline, open questions, and follow-up owners.

Expected output:
  Assign names, write current impact, choose mitigation, set next update time, and record a timeline entry for every decision.
